# Full Stack Developer Capstone

**Project Name:** `fullstack_developer_capstone`

**Repository Name:** `xrwvm-fullstack_developer_capstone`

## About the Project

This project is the IBM Full Stack Software Developer Capstone. It involves building a car dealership web application that allows users to explore dealerships, view dealer information, and submit reviews.

## Technologies Used

- Python
- Django
- JavaScript
- React
- HTML
- CSS
- Node.js
- MongoDB
- SQLite
- REST APIs

## Main Features

- Display dealership information.
- Search dealerships by state.
- View individual dealership details.
- Register and log in users.
- Submit dealership reviews.
- Analyze review sentiment.
- Display car makes and models.
- Run and test the application locally.

## Project Structure

- `server/` — Backend application and frontend code.
- `server/djangoapp/` — Django application and API functionality.
- `server/frontend/` — Frontend pages and React components.

## Purpose

The purpose of this capstone is to apply full-stack development skills by integrating frontend development, backend services, databases, APIs, and user authentication into a dealership web application.
